SEFER LEARNING CALENDAR — DEMO V4
==================================

WHAT CHANGED

1. CONDITIONAL MULTIPLE MARKERS
- A normal project has one two-dimensional saved-place marker.
- Separate Main Text and Commentary markers appear only when the learner selects
  “Main text together with commentary.”
- Each marker remembers its own PDF page, horizontal coordinate, and vertical coordinate.

2. CONSISTENT FRIDAY SETTINGS
- “Lighter Friday” appears only while Friday is selected as a learning day.
- If Friday is deselected, the option disappears and resets to No.
- If Friday is selected again, the option becomes available again.

3. CONDITIONAL-UI PRINCIPLE
The production application should always:
- show only settings relevant to the current choices;
- clear or safely reset settings that become impossible;
- keep project setup, schedule generation, and reader behavior synchronized.

IMPORTANT LIMITATION
This demo still does not use OCR to identify main text, commentary, or natural stopping points.
The multiple markers are learner-controlled positions.

HOW TO OPEN
1. Unzip the folder.
2. Double-click index.html.
3. Keep an internet connection available so PDF.js can load.
